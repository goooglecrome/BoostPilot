YOUR DATA, EXPLAINED

Privacy Policy.

This page explains what information is handled when you visit the BoostPilot website or use the Windows applications, what stays on your PC, and which third-party services are involved.

Home/Privacy Policy

Effective date: 26 November 2026 · Last updated: 26 November 2026

In brief

The BoostPilot website does not currently have user accounts, a newsletter, a payment checkout or a contact form. The reviewed Windows app source stores settings and restore records locally. The original OG app also checks GitHub for updates and has an optional user-started ping test to Cloudflare. The reviewed source does not send hardware readings or restore records to a BoostPilot server.

1. Who this policy covers

This policy applies to the BoostPilot website and the Windows desktop software published through the BoostPilot GitHub repository. It describes the website as currently built and the source versions reviewed for the OG and Beta applications.

The OG source archive reviewed is labelled v1.2.0, while the published OG installer is v1.2.1. The Beta source reviewed is v0.2.0-beta.1. A source review is not a forensic inspection or independent security certification of every distributed installer, and later versions may behave differently. We will update this page when relevant data practices change.

2. Information handled by the website

The BoostPilot website is a static website hosted through Cloudflare. It does not currently ask visitors to create an account, sign in, submit a contact form, subscribe to emails or make a payment.

Like other websites, the hosting provider may process technical request information to deliver and protect the site. This can include an IP address, browser or device information, the page requested, referring page, date and time, and security or error information. See the Cloudflare Privacy Policy ↗.

The Downloads page asks the visitor's browser to retrieve the public BoostPilot release list from the GitHub API. When this happens, GitHub receives the request and its normal technical connection information. Download buttons and source-code links open GitHub. See the GitHub Privacy Statement ↗.

The website currently loads its typefaces from Google Fonts. A visitor's browser connects to Google's font services to retrieve those files. Google may receive normal browser request information; see the Google Privacy Policy ↗.

3. Cookies, analytics and advertising

The current BoostPilot website code does not set analytics or advertising cookies, use advertising pixels, or run a site analytics tracker. Its JavaScript handles the mobile navigation, page year label and public GitHub release-list display.

Cloudflare may use technical security measures as part of hosting and protecting the site. Those services are governed by Cloudflare's own policies and settings. Your browser also controls whether it stores or blocks cookies.

4. Information handled by the Windows apps

BoostPilot Beta v0.2.0-beta.1

The reviewed Beta source reads information from your own Windows PC to show the dashboard and prepare an optimisation plan. This includes CPU and GPU model or sensor readings where available, memory and disk capacity or usage, system uptime, network-interface byte counters, laptop and battery status, and the names and memory use of running processes.

These readings are processed on your PC for display and recommendations. The reviewed Beta source does not contain an analytics or telemetry upload that sends those hardware readings, process details or restore records to BoostPilot. Its network panel reads Windows network-interface counters locally; it does not inspect the contents of your internet traffic.

When you use settings that change Windows, Beta can read or change selected current-user Registry values, Windows startup approval flags and the active Windows power plan. Its Restore Centre records the change type, target, previous value, description and time in a local SQLite database at %LOCALAPPDATA%\BoostPilot-Beta\boostpilot.db. This file stays on your PC and may contain names of startup apps and previous Windows setting values.

Original BoostPilot OG v1.2.x

The reviewed OG source stores your setup choices, including device type, performance goal, optional game names, network type and automation preference, in a local settings file under %LOCALAPPDATA%\BoostPilot. It also stores local rollback files for the Windows settings it changes.

The OG app checks the public GitHub Releases API for a newer version when it starts. This sends a normal web request to GitHub, including the request's technical connection details and the app's update-checker user-agent. The reviewed update-check code asks for the latest release information; it does not send your hardware readings or saved settings.

The OG app also has an optional connection test. Only when you press its test button, it sends up to five ICMP ping requests to 1.1.1.1, Cloudflare's public DNS address, and displays the response times and packet loss. This test reveals normal network connection information to Cloudflare and your network provider; it does not upload files or your saved BoostPilot profile.

These details are based on the OG source archive supplied with the project. The released installer is a separate binary, so the source review should not be treated as a guarantee that every build is identical.

5. Where app information is stored and how long it stays

The reviewed app settings and Restore Centre records are stored in the Windows user's local application-data folder, not in a BoostPilot cloud account. They remain there until removed from the PC. Uninstalling the app may not remove its separate local settings or restore database.

Do not delete the Restore Centre database while you still need its undo history. Website request logs and third-party service records are retained and managed by the relevant providers under their own policies. BoostPilot does not set those providers' retention periods.

6. Sharing and third-party forms

BoostPilot does not sell or rent personal information. The website and reviewed app source do not provide a BoostPilot account system or a server-side user database.

Cloudflare, GitHub and Google are separate service providers involved in hosting, release information, downloads or fonts. Their own privacy policies describe how they process information they receive.

If you complete an application, verification or other form hosted by another organisation, that organisation collects and manages the form information under its own privacy policy. This BoostPilot policy does not cover information submitted directly to that third party.

7. Your choices

You can choose whether to download or run either app. You can choose whether to use the OG connection test. You can also control browser cookies, block third-party fonts, or use browser privacy settings; some website styling may look different if Google Fonts is blocked.

App settings and restore records are stored locally on your Windows profile. The website does not provide a BoostPilot account or online profile for visitors to access or delete.

8. Security

The website is delivered over HTTPS when accessed through its supported Cloudflare address or connected custom domain. The apps make changes on your Windows PC and keep the reviewed restore records locally. Keep Windows and your security software up to date, download installers only from the official BoostPilot GitHub Releases page, and review proposed changes before applying them.

No website, network connection or local application can be guaranteed completely secure. Do not share private logs, passwords or sensitive personal information in public GitHub issues.

9. Changes to this policy

This policy may be updated when the website, applications, hosting or data practices change. The effective and last-updated dates at the top of this page will be changed when a new version is published. Check this page again after installing a major new version.

10. Contact

For questions about this policy, use the BoostPilot GitHub Issues page ↗. Issues are public, so do not include personal details or private information. If your question concerns information held by Cloudflare, GitHub or Google, use that provider's privacy contact process.
