01 / VERSIONS & DOWNLOADS

Choosing a version

Which BoostPilot version should I download?+

For a ready-to-install version, choose BoostPilot OG v1.2.1. It is the latest published stable installer currently listed on GitHub.

Where are the older versions?+

The Downloads page loads all public GitHub Releases, newest first. At the moment, v1.2.1 is the only published installer release. The v1.2.0 ZIP is a source-code archive, not a Windows installer.

Is BoostPilot Beta available yet?+

Yes. BoostPilot Beta 0.2.0-beta.1 is available as a pre-release from the official GitHub Releases page. Beta builds can contain bugs; the original OG v1.2.1 remains the stable release.

Is BoostPilot free?+

The currently published OG installer is available as a free download. Any future paid products or optional services will be clearly described before purchase.

02 / WINDOWS & INSTALLATION

Installing BoostPilot

What does my PC need?+

The current installer is for 64-bit Windows 10 and Windows 11 PCs.

Why does Windows show an unfamiliar-publisher warning?+

The current installer is not digitally code-signed. Only download it from the official BoostPilot GitHub Releases page. Do not install a copy from an unknown mirror.

Will BoostPilot always increase my FPS?+

No software can guarantee an FPS increase on every PC. Results depend on hardware, games, drivers and settings. BoostPilot should report changes honestly rather than promise a particular performance result.

Can I run OG and Beta side by side?+

They are designed as separate applications with different executable names, install folders and Restore Centre databases. The OG app remains the stable version; Beta is optional preview software.

03 / SUPPORT & SAFETY

Need a hand?

Where do I report a problem?+

Open the GitHub Issues page and describe your BoostPilot version, Windows version and the error you saw. Do not post passwords, licence keys or private information.

How do I know a download is official?+

Use the download links on this website or the Releases page at github.com/goooglecrome/BoostPilot. Check the repository address before downloading.

Where can I find the source code?+

The project source is available in the public BoostPilot GitHub repository. Some packaged archives contain source code only and are not installers.
