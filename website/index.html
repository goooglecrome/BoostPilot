GOOD TO KNOW

Questions?

A few quick answers before you install.

Which version should I download?+

For a ready-to-install version, choose BoostPilot OG v1.2.1. The Claude Edition is still being built and tested, so its installer is not available yet.

What does my PC need?+

The current download is a Windows x64 desktop installer. Use a 64-bit Windows 10 or Windows 11 PC.

Where can I find older releases?+

Open the official GitHub Releases page to see the releases currently published for BoostPilot.

Where do I report a problem?+

Visit the GitHub Issues page and describe what happened, which BoostPilot version you use and any error message. Do not post passwords, licence keys or other private information.
